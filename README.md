# ABIA Network — Asia-Pacific Business Innovation Association

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://simonmak-ascent.github.io/abia-network/)

A static website migration of [abia.network](https://www.abia.network/), hosted on GitHub Pages.

## Overview

This repository contains the full static HTML/CSS/JS website for the **Asia-Pacific Business Innovation Association (ABIA)** — 亞太商業創新聯盟. The site has been faithfully migrated from the original Wix-based platform into a clean, lightweight, and fully static implementation suitable for GitHub Pages hosting.

## Pages

| Page | File | Description |
|------|------|-------------|
| 首頁 (Home) | `index.html` | Main landing page with hero, case studies, events, and partners |
| 關於我們 (About) | `about.html` | Organization overview, mission, vision, values, and network |
| 核心服務 (Services) | `services.html` | Three core services: Knowledge, Resources, Consulting |
| 會員權益 (Membership) | `membership.html` | Membership tiers, benefits, and pricing |
| 活動資訊 (Events) | `events.html` | Upcoming and past events |
| 聯絡我們 (Contact) | `contact.html` | Office address, phone, email, and WeChat |
| 章程與條款 (Terms) | `terms.html` | Full membership charter and terms |
| 常見問題 (FAQ) | `faq.html` | Frequently asked questions |

## Technology Stack

- **HTML5** — Semantic, accessible markup (WCAG 2.2 AA compliant)
- **CSS3** — Custom properties, responsive grid, mobile-first design
- **Vanilla JavaScript** — No frameworks, no dependencies
- **Google Fonts** — Noto Sans TC for Chinese typography

## Features

- Fully responsive design (mobile, tablet, desktop)
- WCAG 2.2 AA accessibility compliance
- Skip-to-content link for keyboard navigation
- Semantic HTML with ARIA labels
- Scroll-reveal animations
- Mobile hamburger navigation
- FAQ accordion
- All images served from original Wix CDN
