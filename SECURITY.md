# Security Policy

## Reporting a Vulnerability

Email **simon.pl.mak@gmail.com** with "SECURITY" in the subject.

### Response

- Acknowledgment: within 48 hours
- Assessment: within 5 business days
- Fix: depends on severity

## Scope

This repository is a **static website** (GitHub Pages) — HTML, CSS and vanilla JavaScript with no
server, database, or secrets. The relevant risks are content injection (untrusted HTML/JS) and
supply-chain risk in third-party CDN assets.

## Supported Versions

The latest commit on `main` is the only supported version.
